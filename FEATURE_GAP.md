| SDIO FIFO and FIFOCNT data path. | low | open | DFIFO read writes are synthetic and FIFOCNT does not accurately reflect remaining words. Firmware implementations that track FIFO level for flow control will see incorrect values. |
| SDIO timeout and CRC error generation. | low | open | CTIMEOUT DTIMEOUT CCRCFAIL DCRCFAIL status bits in STA are never set from actual protocol conditions. |
| SPI CRC mode behavior. | low | open | CRCEN bit in CR1 enables hardware CRC calculation over the frame. CR1 CRCEN is stored but the CRC polynomial and running CRC register (RXCRCR TXCRCR) are not updated during transfers. |
| SPI I2S protocol mode. | low | open | I2SCFGR I2SPR registers are stored but I2S audio protocol operation is not implemented. Firmware that switches SPI peripherals to I2S mode will see no audio output. |
| SPI NSS hardware management. | low | open | SSM=0 and SSOE hardware-NSS logic is not implemented. NSS is always treated as software-managed regardless of SSM. |
| SPI OVR MODF clear sequences. | low | open | OVR requires a read of DR then SR to clear; MODF requires a read of SR then a write to CR1. Current model clears these by simplified direct bit operations. |
| SW_SPI CPOL CPHA configuration. | low | open | CPOL is marked TODO and CPHA is not distinguished in edge-sampling logic. Devices requiring non-default SPI mode may receive incorrect bit values. |
| SysTick CTRL ENABLE vs TICKINT separation. | medium | done | SysTick counter now advances continuously from peripheral step() whenever ENABLE=1, independent of TICKINT. TICKINT remains interrupt-only gating via NVIC period setup, so time-keeping progresses even with interrupts disabled. |
| SysTick real 24-bit downcounter and COUNTFLAG. | medium | partially implemented | LOAD and VAL are 24-bit masked and VAL writes clear the counter to 0. Counter updates now track elapsed instructions continuously and COUNTFLAG latches on wrap/zero transitions until CTRL read clears it. Remaining gap is full architectural edge-timing fidelity (including CLKSOURCE-driven rate differences). |
| SysTick LOAD 24-bit mask and CALIB register. | low | partially implemented | LOAD and VAL are masked to 24 bits and CALIB is present with NOREF set. Ten-millisecond calibration value and full SKEW behavior remain unmodeled. |
| SysTick CLKSOURCE bit modeling. | low | done | CLKSOURCE now selects SysTick rate behavior: AHB clock when set and AHB/8 when clear, applied consistently to counter advancement and SysTick interrupt period scheduling. |
| TIM per-instance 16-bit vs 32-bit counter width. | medium | open | All timer counters and ARR CCR registers are stored as 32-bit. TIM2 and TIM5 are 32-bit timers; TIM1 TIM3 TIM4 TIM6-TIM14 are 16-bit. Overflow timing and compare behavior diverge for 16-bit instances when firmware relies on 16-bit natural wraparound. |
| TIM UDIS and URS update-event policy bits. | medium | open | CR1 bits UDIS and URS are not enforced. UDIS=1 should prevent update events and UIF generation. URS=1 restricts update generation to counter overflow or UG bit only and suppresses slave/DMA-triggered updates. |
| TIM ARR preload shadow register and update-event transfer. | medium | open | ARPE is tracked but no shadow register is maintained. When ARPE=1 a new ARR value written by firmware should take effect only at the next update event not immediately. |
| TIM PSC preload and update-event semantics. | low | open | PSC writes take effect immediately. Hardware buffers the new PSC and applies it at the next update event. Firmware that writes PSC mid-count expects the old divisor until the update event fires. |
| TIM RCR off-by-one. | low | open | Update event fires every RCR overflows (when rcr_count >= rcr after increment). RM defines the update event period as RCR+1 counter overflows so the correct test is rcr_count > rcr or equivalently fire when rcr_count reaches rcr+1. |
| TIM slave-mode controller and TRGO master-slave chaining. | low | open | SMCR SMS and TS fields are stored and tracked but no trigger-mode gated reset or external-clock behavior executes. TRGO generation and internal trigger routing between timers for ITRx chains are absent. |
| TIM OC and IC mode decode from CCMR CCER. | low | open | CCMR1 CCMR2 OC mode fields and CCER polarity enable bits are stored but output-compare forced match toggle and PWM generation modes are not executed. Input capture is entirely absent. |
| USART ORE NE FE PE error flag generation. | medium | partially implemented | ORE is now generated both in non-DMA receive flow (new byte while RXNE is set) and in DMAR receive flow (second staged byte arrives before DMA drains pending data). NE FE and PE generation are still not modeled from line/framing/parity fault conditions. |
| USART SR flag clear rules per RM sequences. | low | partially implemented | ORE NE FE PE and RXNE clear on SR read followed by DR read in the modeled receive path; SR write no longer directly clears TC or receive/error flags. Remaining gap: strict TC clear sequencing nuances versus all RM corner cases. |
| USART LIN smartcard IrDA half-duplex mode gating. | low | partially implemented | CR3 HDSEL now enforces single-wire directionality by suppressing RX when TX is active. LIN (CR2 LINEN), Smartcard (CR3 SCEN), and IrDA (CR3 IREN) mode-specific framing/timing behavior remains unmodeled. |
| USB OTG FIFO architecture threshold and ownership. | low | open | Non-periodic Tx FIFO and Rx FIFO ownership arbitration and threshold behavior are heuristic. GRXFSIZ GNPTXFSIZ DIEPTXF sizing registers are stored but not used to enforce FIFO boundaries or generate correct TXFE interrupts per FIFO depth. |
