| RCC comprehensive reset side effects across peripheral domains. | low | open | AHB1 AHB2 APB1 APB2 reset bits in RCC_AHBxRSTR and RCC_APBxRSTR are stored but writing a reset bit does not trigger a peripheral reset or re-initialize peripheral register state. |
| RNG DRDY pacing. | low | done | DRDY now de-asserts after DR read and re-asserts only after a modeled 40-step delay while RNGEN is enabled, preventing immediate-ready tight polling behavior. |
| RNG CECS SECS error-bit generation. | low | partially implemented | RNG now generates deterministic sparse CECS/SECS sticky status events and keeps write-1-clear behavior in SR. Full entropy-source-accurate fault detection and interrupt timing behavior remain simplified. |
| RTC calendar tick and shadow register sync. | medium | partially implemented | TR and DR now advance with a modeled calendar second tick, including BCD rollovers for time/date fields and weekday progression. ISR INIT/INITF freeze/release behavior and RSF clear/resync timing are modeled at a basic level. Alarm A/B, wakeup timer, tamper compare, and full subsecond/shadow fidelity remain unimplemented. |
| RTC WPR unlock sequence and alarm interrupt generation. | low | partially implemented | WPR two-step unlock via 0xCA then 0x53 is enforced. Alarm and wakeup timer IRQ generation paths are still absent. |
| SCB AIRCR SYSRESETREQ and PRIGROUP. | medium | partially implemented | AIRCR writes are VECTKEY-gated. Remaining gap: full ARM priority-group/subpriority arbitration effects are not yet applied in NVIC preemption logic. |
| SCB CPACR floating-point access control. | low | open | CPACR CP10 CP11 bits control FPU access. Current model stores CPACR writes but does not enforce access faults when the FPU is disabled and firmware executes VFP instructions. |
| SDIO complete SD command state machine. | medium | partially implemented | Command dispatching is still scripted, but CMD12 STOP_TRANSMISSION now terminates active data-transfer context and reports completion state, and APP_CMD gating is modeled so ACMD41 requires a preceding CMD55 arm. Unknown-command handling and full SD card state-machine transitions remain incomplete, especially for full multi-block write/read sequencing edge cases. |
| SDIO FIFO and FIFOCNT data path. | medium | partially implemented | DFIFO remains synthetic, but DCOUNT/FIFOCNT now surface active transfer progress for read-side FIFO-backed traffic and write-side DMA-consumed byte countdown paths. Full RM-accurate FIFO push/pop timing and flow-control edge behavior remain incomplete. |
| SDIO timeout and CRC error generation. | medium | partially implemented | Basic CRC/error signaling is now modeled: unknown response-expected commands raise CCRCFAIL, malformed write setup raises DCRCFAIL, and pending read/write transfer stalls can transition through timeout signaling. Full protocol-accurate CTIMEOUT/DTIMEOUT/CRCFAIL generation tied to true SD transaction timing remains incomplete. |
| SPI CRC mode behavior. | low | partially implemented | CRCEN now drives running RXCRCR/TXCRCR updates across DR and DMA traffic using CRCPR polynomial state. Full STM32 CRCNEXT framing and exact hardware sequencing are still incomplete. |
| SPI I2S protocol mode. | low | open | I2SCFGR I2SPR registers are stored but I2S audio protocol operation is not implemented. Firmware that switches SPI peripherals to I2S mode will see no audio output. |
| SPI NSS hardware management. | low | partially implemented | SPI mode-fault path now distinguishes software NSS from hardware NSS and honors SSOE+SPE for master-mode NSS-high behavior. External NSS pin sampling/drive coupling is still not modeled. |
| SPI OVR MODF clear sequences. | low | done | OVR now clears only on DR read followed by SR read, and MODF clears only on SR read followed by CR1 write, matching RM sequencing expectations. |
| SW_SPI CPOL CPHA configuration. | low | done | Software SPI now models CPOL+CPHA mode timing using leading/trailing edges, with CPHA-aware sampling and shifting so non-default SPI modes exchange bits on the correct edge. |
| SysTick CTRL ENABLE vs TICKINT separation. | medium | done | SysTick counter now advances continuously from peripheral step() whenever ENABLE=1, independent of TICKINT. TICKINT remains interrupt-only gating via NVIC period setup, so time-keeping progresses even with interrupts disabled. |
| SysTick real 24-bit downcounter and COUNTFLAG. | medium | partially implemented | LOAD and VAL are 24-bit masked and VAL writes clear the counter to 0. Counter updates now track elapsed instructions continuously and COUNTFLAG latches on wrap/zero transitions until CTRL read clears it. Remaining gap is full architectural edge-timing fidelity (including CLKSOURCE-driven rate differences). |
| SysTick LOAD 24-bit mask and CALIB register. | low | partially implemented | LOAD and VAL are masked to 24 bits and CALIB is present with NOREF+SKEW set to indicate unavailable/inexact reference calibration. Ten-millisecond calibration value (TENMS) remains unmodeled. |
| SysTick CLKSOURCE bit modeling. | low | done | CLKSOURCE now selects SysTick rate behavior: AHB clock when set and AHB/8 when clear, applied consistently to counter advancement and SysTick interrupt period scheduling. |
| TIM per-instance 16-bit vs 32-bit counter width. | medium | done | Timer width masking is modeled: TIM2 and TIM5 use 32-bit counters while TIM1 TIM3 TIM4 TIM6-TIM14 are masked to 16-bit across CNT/ARR/PSC/CCR read-write and tick paths. |
| TIM UDIS and URS update-event policy bits. | medium | done | CR1 UDIS and URS are enforced in update-event generation: UDIS suppresses UIF/IRQ/DMA update signaling, and URS restricts software-triggered update paths while allowing counter-overflow updates. |
| TIM ARR preload shadow register and update-event transfer. | medium | done | ARPE-backed ARR shadowing is implemented with deferred transfer on update events; ARPE=0 applies ARR writes immediately. |
| TIM PSC preload and update-event semantics. | low | done | PSC writes are buffered in a shadow register and only take effect on update event transfer. |
| TIM RCR off-by-one. | low | done | Advanced-timer repetition behavior uses RCR+1 overflows per update event (event released only after `rcr_count` reaches `rcr + 1`). |
| TIM slave-mode controller and TRGO master-slave chaining. | low | open | SMCR SMS and TS fields are stored and tracked but no trigger-mode gated reset or external-clock behavior executes. TRGO generation and internal trigger routing between timers for ITRx chains are absent. |
| TIM OC and IC mode decode from CCMR CCER. | low | open | CCMR1 CCMR2 OC mode fields and CCER polarity enable bits are stored but output-compare forced match toggle and PWM generation modes are not executed. Input capture is entirely absent. |
| USART ORE NE FE PE error flag generation. | high | partially implemented | ORE is now generated both in non-DMA receive flow (new byte while RXNE is set) and in DMAR receive flow (second staged byte arrives before DMA drains pending data). | USART SR flag clear rules per RM sequences. | high | partially implemented | ORE NE FE PE LBD and RXNE clear on SR read followed by DR read in the modeled receive path; SR write no longer directly clears TC or receive/error flags. | USART LIN smartcard IrDA half-duplex mode gating. | high | partially implemented | CR3 HDSEL now enforces single-wire directionality by suppressing RX when TX is active.
