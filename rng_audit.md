# RNG Audit (RM0090 RNG Source-of-Truth)

Scope
- Peripheral audited: src/peripherals/rng.rs
- Reference source: STM32F4 hardware RNG control/status/data behavior.

## Executive result
RNG provides deterministic pseudo-random output when enabled, which is sufficient for bring-up but not RM-accurate entropy/error behavior.

Wrong
1. DRDY is effectively always available when RNGEN is set.
2. Error bits are not generated by real clock/seed fault conditions.

Missing
1. CECS/SECS generation and clear semantics from actual error conditions.
2. Throughput/latency behavior and data-ready pacing.

Incomplete
1. CR bit coverage is minimal.
2. Status transitions are simplified to RNGEN gating.

## High-priority correction targets
1. Model DRDY pacing rather than always-ready behavior.
2. Add realistic sticky error-bit generation/clear behavior.
